# Neon Beyond Links

Tema landing page tiga link dengan gaya futuristik hitam, biru elektrik, dan hijau neon. Tidak memerlukan framework atau proses instalasi.

## Cara memakai

1. Buka `index.html` untuk melihat hasil.
2. Cari tiga elemen `class="link-card"` di `index.html`.
3. Ganti setiap `href="#"` dengan alamat tujuan Anda.
4. Ganti judul, deskripsi, Instagram, Telegram, dan WhatsApp sesuai kebutuhan.
5. Unggah seluruh isi folder ke repository GitHub lalu aktifkan GitHub Pages.

## Isi file

- `index.html` — struktur dan teks
- `style.css` — seluruh tampilan, responsif, dan animasi
- `script.js` — bintang, glow, reveal, dan counter

Tema dibuat sebagai karya original yang terinspirasi dari estetika futuristik referensi pengguna.
